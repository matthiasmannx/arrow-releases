# Arrow

**Aim. Release. Arrive.**

Arrow is a calm, fast browser for macOS: spaces with their own profile, a sidebar that adapts to how you work, and everything you expect from Chromium.

## Download

[Download Arrow for Mac (Apple Silicon)](https://github.com/matthiasmannx/arrow-releases/releases/latest/download/Arrow.dmg)

Open the .dmg and drag Arrow to Applications. Arrow updates itself after that.

This repository only contains the releases (signed and notarised by Apple), not the source code.
